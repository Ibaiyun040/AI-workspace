## 指标在量化什么

交易所不公布保证金，所以「平均杠杆」看不到。对**单一合约**用三个可观测代理：

| 量 | 定义 | 含义 |
|---|---|---|
| **BIL**（账面隐含杠杆） | `OI / max(近6h合约成交额, 0.25×24h现货额, 2%×市值)` | 要把这笔 OI 平掉，相当于几倍近期可变现流动性 |
| **空头相对杠杆** | `1 / 账户多空比` | 名义对等时，空头账户远多于多头 → 散户空头更碎、惯用更高杠杆 |
| **SFI**（0–100） | 空头拥挤 + 大户空头 + 24h OI 膨胀 + BIL + OI/市值 + 顺涨扩仓 + 流动性真空 | 轧空脆弱性 |

**强烈警报（全局同一组阈值）**：`SFI≥62` 且当时 `OI≥$100万`，且 24h 成交额缺失或 `≥$15万`；若有账户多空比，还要求空头账户占比 `≥60%`。

资金费率、溢价指数、`last_funding_rate`、mark–index 基差在适配层丢弃，特征函数读不到。

## 怎么放进你的风控

1. **硬门槛**：该所该合约 `OI<$100万` 不报警。  
2. **减仓/禁止新开空**：SFI≥62 且空头账户占比≥60%（有多空数据时）。BIL 高 + 顺涨扩仓，是 TUT 那种「正费率诱空」的结构，不需要看费率也能认出来。  
3. **不要用本指标过滤所有套利空**：JELLY 那种厚盘、BIL 低、只是价格自己拉的，SFI 不会高。这正是去掉资金费率的目的——庄家把费率钉在正的，不会单独触发。  
4. **误报要当真**：Gate 上约四成强警报在 7 天内没有出现翻倍/小时 25%/空爆 3%。适合降杠杆、缩敞口，不适合当开多信号。  
5. **Bitget 实盘**：历史 OI 拉不到，但**实时** ticker 的 `holdingAmount` 可以现算 OI，和 Gate 多空一起用。
